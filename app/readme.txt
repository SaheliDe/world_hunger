To run the application start backend.py and navigate to http://127.0.0.1:5000 in your browser

In order to actually run the algorithm, you need to add a population density data file like nga_general_2020.csv (e.g. for Nigeria).
Add this file to the app folder (where this readme is located as well)

You can download these files for any country in the world from https://hub.worldpop.org/geodata/listing?id=77
